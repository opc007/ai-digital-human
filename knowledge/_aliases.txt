# 自定义同义组（可选）
#
# 检索用的是「中文 bigram 字面匹配 + 同义组扩展 + IDF 加权」。
# 同义组解决的问题：观众问「贵不贵 / 值不值」，知识库写「售价 / 定价」，
# 字面零重叠 → 检索不到 → 只能回答「记下了」。这里把它们挂到一起。
#
# 格式：每行一组，组内词互为别名。空格、| 、逗号、顿号都能分隔。
# 以 # 开头的行是注释，空行忽略，少于 2 个词的行忽略。
#
# 换自己的产品时，往下面加你自己的组就行——把
# 「观众会怎么问」和「知识库里怎么写」对应上，效果立竿见影。
#
# 内置已有 8 组常见问法（价格/耗时/用法/支持/对比/售后/功能/账号），
# 这里只写你这个产品特有的。

# —— 示例：观众问法 知识库用词 ——
分屏 合成 | 官网 展示 | 屏幕 左边
成片 出片 时间 | 多久 生成
投流 投放 | 推广 流量
