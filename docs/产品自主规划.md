# 产品自主规划（给开发自己用）

> 用户是业余、不懂技术的人。不要等用户指点该做什么。  
> 原则：**尽快让用户看到「数字人回了我一句」**，再引导换真素材和真推流。

## 业界共识（已吸收）

1. SaaS 上架成功关键：缩短「首次价值时刻」（Time-to-Value）
2. 给清晰路径，不要一次甩全部设置
3. 用产品本身教学，而不是长文档
4. 数字人链路 = 形象 + 语音 + 对话 + 推流；缺一就要有降级（演示）

## 我们的首次价值时刻

**点一个按钮 → 30 秒内数字人用文字/状态回复「你好」**（仅预览即可）

## 当前产品结构

| 页面 | 角色 |
|------|------|
| `/` 首页 | 一键体验 + 准备度 + 4 步说明；进阶才展开完整开播设置 |
| `/materials` | 素材车间（上传/ComfyUI/TTS） |
| 云端配置抽屉 | Key / ComfyUI / Ollama |

## 自动决策规则

| 情况 | 系统行为 |
|------|----------|
| 无动作视频 | `demo/ensure` 生成占位 mp4 |
| 无 LLM Key | Mock 演示回复 |
| 无 TTS Key | 静音/本地 edge 回落 |
| 无推流码 | 仅允许预览或阻断真平台 |
| 缺 idle | preflight 阻断开播 |

## 迭代优先级（自主执行）

1. 保主路径：一键体验永远可用  
2. 真素材替换路径清晰  
3. 真 Key 配置与测试  
4. 真平台推流说明  
5. 再谈口型质量、弹幕、多租户  

## 不要做的

- 不要一上来微服务/计费/IP 商店  
- 不要默认要求用户会 ComfyUI  
- 不要让「配置」挡住「先玩一下」
