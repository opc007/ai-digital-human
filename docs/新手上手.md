# 新手上手（不用懂技术）

> 这份文档假设你**不会敲命令、不认识 Python**。
> 照着做，一步一步来就行。全程大约 10 分钟。

---

## 一、先装两个东西

### 1. Python（必需）

去 <https://www.python.org/downloads/> 下载安装。
**Windows 用户注意**：安装界面第一个页面有个勾选项叫
`Add Python to PATH`，**一定要勾上**，不然后面会失败。

装完不用管它，脚本会自己找。

### 2. FFmpeg（必需，用来合成画面）

| 你的系统 | 装法 |
|---|---|
| Mac | 打开「终端」（聚焦搜索里搜 Terminal），粘贴 `brew install ffmpeg` 回车。<br>没有 Homebrew 的话先到 <https://brew.sh> 跟着装一下。 |
| Windows | 打开 PowerShell，粘贴 `winget install ffmpeg` 回车。 |
| Linux | `sudo apt install ffmpeg` |

> 也可以用 `bash start.sh --check` 让脚本帮你查缺什么，它会告诉你缺哪个。

---

## 二、启动

在项目文件夹里**右键 → 打开终端**（Mac 是右键 → 新建终端窗口），
粘贴这一行，回车：

```bash
bash start.sh
```

第一次会慢一些（要装依赖，几分钟），之后每次都是秒开。

跑完会打印一个地址，**复制到浏览器打开**，看到数字人控制台就成了。

```
  数字人控制台正在启动…
    搞定了
  浏览器打开这个地址：
      http://127.0.0.1:8100
```

脚本还会自动帮你打开浏览器。

**卡住了怎么办：**

| 命令 | 作用 |
|---|---|
| `bash start.sh` | 启动 |
| `bash start.sh --check` | 只体检不启动，看看缺什么 |
| `bash start.sh --stop` | 停掉 |
| `bash start.sh --reset` | 依赖装坏了，重来一遍 |

---

## 三、第一次试玩（3 步，1 分钟内看到效果）

1. 页面里**什么都不用填**，直接点「**开始直播**」，平台选「**仅预览**」
2. 在下面的聊天框**发一句话**，比如「你好」
3. 数字人会**开口说话**，画面里出现它的口型

> ⚠️ **听不到声音？** 点右上角「🔊 开声」。
> 浏览器默认会静音自动播放的视频。

## 四、两种玩法

### 玩法 A：普通互动直播

跟观众聊天，数字人实时回答。适合娱乐、陪伴类。

### 玩法 B：宣讲带货（分屏 + 知识库）

左边显示你的产品官网，右边数字人讲解。适合卖东西、讲课程。

**它会自动做三件事：**

| | 做什么 |
|---|---|
| 🎤 **有人提问** | 立刻按你的知识库回答，**不会瞎编** |
| ⏰ **没人提问** | 超过 45 秒没人说话，自动播一条宣讲词 |
| 🖼️ **画面** | 左边官网截图，右边数字人 |

**怎么换成自己的产品：**

1. **知识库** —— 把 `knowledge/` 文件夹里那个 `.md` 改成你自己的产品介绍、价格、常见问题
2. **宣讲稿** —— 改 `knowledge/promo_script.md`，**一行一句**，闲时轮着播
3. **产品名和网址** —— 改 `configs/rooms/promo.yaml` 里的 `product_name` 和 `website_url`

**怎么确认它答得上？** 回到控制台，「开播前检查」下面有一块「**宣讲模式**」，
里面能看到知识库读进去多少段、宣讲稿几条。**在下面输入框试问一句**，
比如「贵不贵」，它会告诉你能不能答上来、引用的是哪一段。

> **答不上来怎么办？** 说明观众的问法和你知识库里的写法不一样。
> 打开 `knowledge/_aliases.txt`，照着里面的格式加一行把它们挂上就行。
> 那个文件开头有例子。

## 五、想让它说自己的话（接 Key）

不填 Key 也能玩，但它会：
- 说话用**微软的免费语音**（联网才能用）
- 回答用**内置固定话术**，不是真的在理解你

想要**它真的能聊天**、**声音更像真人**，去 <https://platform.deepseek.com> 注册拿一个 Key
（新用户一般有免费额度），然后：

- 进控制台 → 右上角「**配置**」 → 填进去 → 点测试

**Key 绝对不要**发给别人、不要贴到 Issue 里。它只保存在你自己电脑上。

## 六、推到抖音/快手这些平台

1. 电脑上装该平台的「直播伴侣」
2. 在里面开始直播，找到「**第三方推流 / RTMP**」
3. 复制**服务器地址**和**推流码**
4. 回到控制台，平台选**抖音**（或快手/视频号/小红书），把推流码粘进去
5. 点「**开始直播**」，回到直播伴侣确认画面进去了

> 推流码会过期，每次开播都要重新复制。
> 第一次建议先在「仅预览」把效果调好，再推真平台。

## 常见问题

**Q：提示「没装 ffmpeg」**
回上面第一节装 FFmpeg。

**Q：依赖装到一半失败 / 网络报一堆错**
`bash start.sh --reset` 然后重来。还不行就换手机热点。

**Q：数字人在动但是没声音**
多半是浏览器静音了，点画面上方的「🔊 开声」。
还是没声就去「配置」里点一下「语音试听」，它会告诉你卡在哪。

**Q：换成自己的照片**
把照片放到 `data/avatars/demo/source/photo.jpg`。
想要真的动起来（眨眼、说话口型）需要 NVIDIA 显卡，没有的话会退化成
「静态图 + 声音」，流程照样能跑通。

**Q：宣讲模式里「知识库：0 段」**
`knowledge/` 文件夹里没放 `.md` 或 `.txt` 文件，或者格式不对。
